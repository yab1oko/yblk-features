# CurseForge page kit — Features

Upload: `build/libs/Features_Forge_1.0.jar`

## Description — how to paste

CurseForge often breaks when copying from Markdown code blocks. Use one of these files instead:

1. **`curseforge-description.txt`** — open in Notepad → Ctrl+A → Ctrl+C → paste into CurseForge (easiest).
2. **`curseforge-description.html`** — if the editor has an HTML / source mode.
3. **`curseforge-description-ru.txt`** — Russian text (for yourself / other sites).
